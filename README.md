# QUICUT 产品规划（MVP）

一个轻量桌面端视频分割工具，帮助用户按时间点快速切分长视频，并在速度与画质之间提供清晰可控的选择。

## 1. 产品定位

- **目标用户**：剪辑新手、自媒体运营、课程切片、会议录像整理用户。
- **核心价值**：
  - 快速按时间点切分长视频
  - 尽量无损画质输出
  - 低门槛桌面工具，启动快、安装轻

## 2. 核心能力（MVP）

1. 导入单个视频并预览
2. 添加多个切点（时间输入 / 播放位置打点）
3. 批量导出分段
4. 导出模式：
   - **极速无损（默认）**：`-c copy`，速度快且不重编码
   - **精准高质（可选）**：切点附近重编码，实现更精确边界

## 3. 技术方案建议

- **桌面框架**：Tauri（优先轻量）
- **前端**：React 或 Vue（二选一即可）
- **视频处理**：FFmpeg + FFprobe
- **存储（可选）**：SQLite（保存历史任务和预设）

## 4. 关键流程

1. 用户导入视频
2. FFprobe 读取媒体信息（时长、编码、关键帧信息）
3. 用户在时间轴添加切点
4. 系统将切点转换为分段区间
5. 调度 FFmpeg 批量导出并回传进度
6. 输出成功/失败汇总与日志

## 5. 导出策略（高质量与速度平衡）

### 5.1 极速无损（默认）

- 命令思路：`-ss/-to + -c copy`
- 优势：速度快、画质无损、CPU占用低
- 限制：切点通常对齐关键帧，不一定逐帧精确

### 5.2 精准高质（高级）

- 命令思路：切点附近小段重编码，其余流拷贝
- 优势：切点更精确，观感高质量
- 成本：速度下降，实现复杂度更高

## 6. 功能优先级

### P0（首发）

- 拖拽导入
- 播放/暂停/跳转
- 多切点管理
- 批量导出
- 导出进度、失败提示

### P1（增强）

- 缩略图辅助定位
- 批量命名规则
- 多任务队列
- 导出模板保存

### P2（进阶）

- 自动场景切分
- GPU 编码支持（NVENC/QSV/AMF）
- 任务恢复与诊断包

## 7. 里程碑（6周）

- **第1周**：FFprobe/FFmpeg 可行性验证，跑通分割命令
- **第2-3周**：完成 MVP 主流程（导入、打点、导出）
- **第4周**：稳定性优化（大文件、异常处理）
- **第5周**：精准模式与预设功能
- **第6周**：打包发布（Windows/macOS）

## 8. 验收标准（MVP）

- 30 分钟 MP4 在默认模式下可批量切分成功
- 输出片段可正常播放，音画不同步率可控
- 普通用户可在 3 分钟内完成“导入-打点-导出”流程

## 9. 下一步落地建议

1. 先做 Windows 首发版本
2. 先支持 MP4(H.264/H.265)
3. 默认展示“极速无损”并对关键帧限制做提示
4. 收集真实用户样本后再扩展精确切点与 AI 能力

## 10. 已开始实施：CLI 原型

仓库已提供可运行的命令行原型：`src/quicut.py`，可用于验证“切点解析 -> 分段规划 -> FFmpeg 执行”链路。

### 10.1 仅生成分段规划（推荐先验证）

```bash
python3 src/quicut.py \
  --input /path/to/long-video.mp4 \
  --cuts 00:03:20 00:18:40 00:42:10 \
  --duration 3600 \
  --list-segments \
  --plan-json ./plan.json \
  --dry-run
```

### 10.2 实际导出

```bash
python3 src/quicut.py \
  --input /path/to/long-video.mp4 \
  --cuts 200 900 1800 \
  --mode copy \
  --output-dir ./outputs
```

### 10.3 环境自检

```bash
python3 src/quicut.py --check-env
```

参数说明：
- `--cuts-file`：从文本文件读取切点（每行一个，支持 `#` 注释）
- `--list-segments`：导出前打印分段规划
- `--min-segment`：限制最短分段时长，避免误切出超短片段
- `--plan-json`：将分段规划导出为 JSON，便于后续 GUI/任务系统复用
- `--mode copy`：极速无损模式（关键帧对齐）
- `--mode reencode`：重编码模式（更精确但更慢）
- `--show-progress`：导出时解析并打印 ffmpeg 进度（out_time_ms/speed）
- `--output-ext`：指定输出后缀（如 `mp4`/`mkv`）；不指定时 copy 继承源后缀，reencode 默认 `.mp4`
- `--check-env`：打印环境可用性（`ffmpeg`/`ffprobe`/`pyinstaller`）并返回状态码
- 运行预检：实切需 `ffmpeg`，自动探测时长需 `ffprobe`（若传 `--duration` 可跳过 `ffprobe`）


## 11. 一键打包与冒烟测试

已提供脚本可直接打包 CLI 为单文件可执行程序：

```bash
bash scripts/package_cli.sh
```

产物默认在：`dist/quicut`（Linux/macOS）。

可先运行冒烟测试：

```bash
bash scripts/smoke_test.sh
```

- 若环境有 `ffmpeg`：会生成 5 秒样例视频并执行真实切割校验。
- 若环境无 `ffmpeg`：会自动降级为 dry-run 规划链路校验。
